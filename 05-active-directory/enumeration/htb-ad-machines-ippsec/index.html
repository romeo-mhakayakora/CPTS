    📌 Overview¶

    Active Directory practice machines on Hack The Box that have IppSec video walkthroughs, grouped by difficulty and kept in oldest-to-newest release order. Each row links the HTB machine page and the verified IppSec YouTube video.

    Video IDs were verified via YouTube oEmbed (author = IppSec, title matches the machine). Two machines (Return, Object) could not be reliably confirmed and are flagged — search ippsec.rocks before treating them as covered.

    🧭 Recommended CPTS practice order¶

    Progress from foundational AD enumeration to complex attack chains:

    1. Foundation: Active → Forest → Sauna
    2. Core AD enumeration & exploitation: Timelapse → Support → Resolute → Cascade
    3. Intermediate attack chains: Intelligence → Escape → Authority → Manager → Certified
    4. Advanced AD: Blackfield → Search → Flight → Vintage → Haze

    🛠️ How to use these¶

    • Watch the IppSec video after attempting the box solo — treat it as the debrief, not the tutorial.
    • For each box, log the AD technique used (Kerberoast, AS-REP, ACL abuse, delegation, relay, etc.) into the relevant enumeration/breaching notes file.
    • Cross-check coverage on ippsec.rocks before assuming a machine has a walkthrough.

    💻 Notes¶

    • Difficulty labels are HTB's own classifications.
    • This is not a verified inventory of every IppSec AD video — Return and Object links are unconfirmed.
